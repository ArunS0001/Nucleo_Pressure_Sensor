How to run the project in Nucleo G491RE

1.) Right click on zxc1 project and click on Run as C\C++ STM32 Application.
2.) Click Ok.
3.) Download of program should start into board.
4.) Download should complete with below message:
Time elapsed during download operation: 00:00:00.428

Verifying...

Time elapsed during verifying operation: 00:00:00.041
Download verified successfully

Shutting down...
Exit.

5.) Open TeraTerm and select a serial port. 
6.) Click  on reset button on nucleo board.
7.) The message called: Welcome to STM32 world ! must be visible on the screen.

8.) Select demonstration code , select all options under human machine interface.

11.) Click on generate code on top.

14.) The directtory structure after code generation is as follows:

 15.) DOuble click on .cproject to open the project in stm32cubeide.
